# Генератор CPS для AmneziaWG

Пакет: `internal/server/integrations/nativeawg/cps`.
Генератор подключён к панели настроек AmneziaWG через защищённый admin API.
Кнопка генерации заполняет только черновик формы. Сохранение и применение
выполняются отдельно кнопкой «Сохранить и применить». Агенты не импортируют
генератор; они получают готовые CPS-строки через gRPC.

После I5 кнопка «Сгенерировать I1–I5» раскрывает панель: количество 1–5
(по умолчанию 1), профиль и, для DNS/QUIC, сервис или свой домен.
Успешная генерация заполняет I1–IN, очищает оставшиеся I-поля и сворачивает
панель. Ошибка оставляет прежние значения и параметры генерации.
Отмена или закрытие диалога отменяет запрос; остальные поля формы не меняются.

`POST <admin-prefix>/api/v1/nodes/amneziawg-signatures` принимает
`count`, `profile`, необязательные `service` и `server_name`; возвращает
`{"signatures":["..."]}`. Нужны admin-сессия, разрешение изменения серверов
и стандартная CSRF-защита. При включённых rate limits действует лимит
30 запросов в минуту на IP. Генерация не обращается к базе данных.

## Вызов

```go
chain, err := cps.Generate(ctx, cps.Options{
    Profile: cps.QUIC,
    Service: cps.Google,
})
if err != nil {
    return err
}
// chain.Signatures[0].CPS ... chain.Signatures[4].CPS соответствуют I1 ... I5.
```

`Profile`: `auto`, `dns`, `stun`, `quic`. Пустое значение означает `auto`.
`Service`: `auto`, `google`, `apple`, `microsoft`, `custom`.
Для `custom` требуется `ServerName`: DNS-имя без схемы, порта, пути и wildcard.
Поддерживается IDNA. IP вместо имени отклоняется.

`ServerName` используется только внутри пакета: в DNS-вопросе или TLS SNI.
Генератор не разрешает это имя и не подключается к нему.
STUN является общим протокольным профилем без привязки к компании и без SNI:
для него нельзя задавать конкретный `Service` или `ServerName`.
Автоматический режим не выбирает STUN, если явно запрошен сервис или DNS-имя.

Возвращается ровно пять сигнатур. У каждой есть CPS-строка, размер UDP payload
и признак динамических подстановок. Ошибка отменяет весь результат; частичная
цепочка не возвращается. Сигнатуры не содержат VPN-ключей и паролей.

## Вариативность

Нет каталога готовых CPS-строк. Имена известных сервисов служат исходными
данными генерации, а сами пакеты каждый раз создаются заново.

### DNS

- `miekg/dns` формирует реальные запросы A, AAAA и HTTPS к одному выбранному имени.
- Регистр букв DNS-имени варьируется без изменения его смысла.
- Размеры меняются с помощью EDNS Padding: случайные 0–16 байт нулевого
  заполнения, без округления до крупных блоков. Это сокращает CPS-строки;
  такое заполнение не предназначено для сокрытия длины DNS-запроса.
- Идентификатор запроса заменяется `<r 2>`, клиентский EDNS Cookie -- `<r 8>`.
- Подстановки меняются при каждом выполнении CPS в клиенте. Длины и структура
  пакета от этого не меняются; аутентификация или контрольная сумма DNS отсутствует.

### STUN

- `pion/stun/v3` формирует Binding Request с допустимым атрибутом PADDING.
- Новый идентификатор транзакции и длина PADDING выбираются при генерации.
- PADDING занимает 12, 16, 20 или 24 байта; полный STUN-пакет — 36–48 байт.
- Все 96 бит идентификатора используют `<r 12>`. В PADDING восемь случайных
  байт сохраняются в шаблоне, остальные используют `<r N>`, `<rc N>` или `<rd N>`.
- MESSAGE-INTEGRITY и FINGERPRINT не добавляются: динамические подстановки
  сделали бы их недействительными. Такие неаутентифицированные Binding Request
  с PADDING являются отдельными транзакциями, а не ответами удалённого сервиса.

### QUIC

- `quic-go` формирует настоящие защищённые QUIC v1 Initial с TLS 1.3, ALPN `h3`
  и выбранным SNI. Это стек Go, не точная копия fingerprint Chrome или Safari.
- Адаптер `net.PacketConn` работает только в памяти: сетевой сокет не открывается.
- Размер Initial остаётся 1200, 1216 или 1232 байта: уменьшать его ниже
  протокольного минимума 1200 байт ради короткой CPS-строки нельзя.
- Захватываются первые пять исходящих датаграмм одной попытки handshake,
  включая повторные передачи. Connection IDs и ClientHello относятся к одной
  попытке, а номера пакетов и ciphertext различаются.
- Сбор обычно занимает около секунды; действует верхний предел 12 секунд
  и более короткий deadline вызывающей стороны.
- Каждый новый вызов создаёт новую попытку с новым случайным материалом.
- Защищённые байты сохраняются статическими CPS-литералами: произвольные
  `<r>` внутри QUIC нарушили бы целостность пакета.
- CPS не воспроизводит исходные интервалы повторных передач и не завершает
  QUIC handshake с настоящим сервисом. Цепочка QUIC является связанной единицей;
  независимая замена её элементов данными из другого вызова некорректна.

Максимальный payload каждого пакета -- 1232 байта. Этот предел учитывает
UDP/IPv6 при минимальном path MTU 1280, но не гарантирует отсутствие проблем
на любом маршруте. Статические данные разбиваются на короткие соседние CPS-теги
без изменения байтов; пакет не обрезается.

## Что проверено

- DNS и STUN разбираются соответствующими библиотеками после многократных
  случайных подстановок CPS, а не только до их добавления.
- QUIC Initial расшифровывается настоящим QUIC-сервером в loopback-тесте;
  сервер извлекает ожидаемый TLS SNI. Только этот тест использует UDP-сокеты.
- Все пять QUIC-пакетов принадлежат одной попытке и не дублируют байты друг друга.
- Проверены отмена, deadline, ограничения размера и изоляция зависимостей агентов.

Импорт в конкретные версии AmneziaVPN и прохождение сетевой фильтрации пока
не проверялись. Сходство начала обмена с известным протоколом не доказывает
его неотличимость от трафика Google, Apple или Microsoft. Генератор ничего
не обещает относительно IP allowlist, DPI и активных проверок сервера.
