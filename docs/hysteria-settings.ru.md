# Настройки Hysteria

Одна форма используется при установке и при редактировании сервера. Установка
создаёт конкретную конфигурацию: обфускация и маскировка выключены, защита
внутренних ресурсов включена, страны не выбраны. Остальные начальные значения
описаны в `internal/protocol/hy2config.Defaults` и передаются форме сервером.

## Границы

Форма не принимает `auth`, `trafficStats`, TLS-ключи, параметры ACME и настройки
связи агента с LazGate. Агент сохраняет эти разделы существующего файла.
Смена публичного домена меняет только список доменов управляемого ACME;
Hysteria самостоятельно получает сертификат. В локальном Docker вместо ACME
используется тестовый сертификат: домен обязан входить в него.

Публичный порт отделён от порта процесса для Docker/NAT. Пока публичный порт
не меняется, внутренний сохраняется. При смене публичного порта агент меняет
и порт процесса; внешний firewall и Docker-проброс автоматически не изменяются.

## Сохранение и применение

`GET/PUT /<admin-prefix>/api/v1/nodes/<id>/hysteria-settings` защищены штатной
админской авторизацией, правами и CSRF. PUT использует `config_version_ms`
для защиты от перезаписи параллельных изменений и возвращает 202.

Настройки с секретами зашифрованы штатным SecureStore. GET не возвращает пароли
обфускации и выходных прокси. Пустой пароль при редактировании сохраняет прежний.
Конфигурация и выданные клиентские ссылки обновляются одной транзакцией;
токены страниц и подписок сохраняются.

Очередь содержит только ревизию настроек. При доставке сервер читает последнюю
конфигурацию, отправляет EditServerConfig через существующий gRPC stream и
проверяет node_id, ревизию и correlation_id ответа. Устаревшие ревизии не
применяются. Данные восстанавливаются из desired state после переподключения.

Агент проверяет параметры, сохраняет rollback-копию, атомарно заменяет файл,
перезапускает Hysteria и проверяет systemd и Stats API. При ошибке восстанавливает
прежний файл и сервис. ACK подтверждает только успешное применение.
GUI различает сохранение и фактическое применение; подробности внутренних
ошибок остаются в журнале сервера с публичным error_id.

При смене домена, порта или обфускации клиентам нужно обновить конфигурации.
Перезапуск разрывает текущие VPN-соединения.

## ACL-защита

Защитные правила стоят перед пользовательскими: блокируются loopback,
приватные, link-local и служебные диапазоны, включая metadata endpoints.
Выбор страны создаёт `reject(geoip:<код>)`, но не добавляет GeoSite-категории.
Это запрет доступа через VPN, не bypass на устройстве пользователя.

При подключении существующей установки импортируется фактическая конфигурация.
Без сохранённого снимка редактирование отклоняется: подмена неизвестных настроек
значениями по умолчанию недопустима.

## Статический ответ маскировки (String)

- «Простой текст»: многострочный текст, `Content-Type: text/plain; charset=utf-8`, HTTP 200.
- «HTML»: многострочный HTML, `Content-Type: text/html; charset=utf-8`, HTTP 200. Предпросмотр с исполнением HTML в админке не выполняется.
- «Вручную»: содержимое, HTTP-код и произвольные HTTP-заголовки в JSON.
- «Автоматически»: браузер выбирает один из 154 английских сонетов Шекспира; «Другой сонет» выбирает другой. Ответ отдаётся как простой текст с HTTP 200.

Набор оригинальных сонетов (общественное достояние) включён в статические ресурсы:
источник — https://www.gutenberg.org/ebooks/1041. Внешних запросов и серверного
выбора сонета нет. Сохраняется готовый текст: при открытии формы, применении
или перезапуске агента он не меняется. Режим редактора определяется по сохранённым
заголовкам, HTTP-коду и содержимому; отдельного серверного поля для него нет.

HTTP-код, заголовки и содержимое доступны для редактирования во всех режимах.
Значения по умолчанию устанавливаются только при переключении на текст, HTML
или автоматический режим. «Вручную» оставляет текущие значения. При открытии
формы и сохранении пользовательские значения не переопределяются.

## Проверки

`make check` выполняет генерацию, Go/UI-тесты и vet.
Дополнительная проверка трёх режимов обфускации настоящим бинарником Hysteria
в локальном контейнере, без изменения работающего сервиса:

```sh
LAZ_HYSTERIA_TEST_CONTAINER=lazgate-settings-hysteria-1 \
  go test -run TestNativeHysteriaConfiguration -v ./internal/protocol/hy2config
```
